# Squares in Squares

An interactive atlas of the unit-squares-in-a-square packing problem, one n at a time:
proven results, constructions, the current public best, and a game mode to try to beat it.

Live site: https://raojohng.github.io/squares-in-squares/

Static HTML, CSS and JavaScript; no build step. Open `index.html` locally or visit the live site.
